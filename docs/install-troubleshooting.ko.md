# APK 설치가 안 될 때 (갤럭시 S24+ 기준)

**순서대로** 하세요. 1번을 건너뛰면 나머지를 다 해도 설치되지 않습니다.

---

## 1. 자동 차단 끄기 ← 갤럭시에서 가장 흔한 원인

One UI 6부터 삼성이 넣은 기능입니다. 켜져 있으면 **스토어 밖에서 받은 앱은 전부 설치가 거부됩니다.**
USB 케이블로 설치하는 것까지 막습니다.

```
설정 ▸ 보안 및 개인정보 보호 ▸ 자동 차단 ▸ 끄기
```

> 검색이 빠릅니다: 설정 맨 위 돋보기에 **자동 차단** 입력

## 2. Play 프로텍트 검사 끄기

접근성 권한을 사용하는 앱은 Play 프로텍트가 특히 강하게 막습니다.

```
Play 스토어 ▸ 우측 상단 프로필 아이콘 ▸ Play 프로텍트 ▸ 우측 상단 톱니(⚙)
  ▸ "Play 프로텍트로 앱 검사" 끄기
```

설치가 끝난 뒤 다시 켜도 앱은 계속 동작합니다.

## 3. 알 수 없는 앱 설치 허용

Android 8부터 **APK를 여는 앱마다 따로** 허용해야 합니다.
브라우저로 받았으면 브라우저에, `내 파일`로 열면 `내 파일`에 허용해야 합니다.

```
설정 ▸ 애플리케이션 ▸ 우측 상단 ⋮ ▸ 특별한 접근 ▸ 알 수 없는 앱 설치
  ▸ [APK를 여는 앱 선택] ▸ "이 소스 허용" 켜기
```

## 4. 이전 버전 삭제

v1.0.0을 이미 설치했었다면 **반드시 먼저 삭제**하세요.
서명 키가 바뀌어서 덮어쓰기가 안 됩니다. (`서명이 일치하지 않습니다` 오류)

## 5. 다시 설치

`내 파일 ▸ 내장 메모리 ▸ Download ▸ IncognitoBlocker.apk` 탭 → 설치

## 그래도 안 되면: 오류 메시지별 원인

| 화면에 나오는 말 | 원인 | 해결 |
|---|---|---|
| 자동 차단으로 차단됨 / 허용되지 않은 출처 | 삼성 자동 차단 | 1번 |
| 안전하지 않은 앱 / 차단된 앱 / 유해할 수 있음 | Play 프로텍트 | 2번 |
| 보안상의 이유로 차단 / 설치 버튼이 회색 | 알 수 없는 출처 미허용 | 3번 |
| 기존 패키지와 서명이 일치하지 않음 | 구버전이 깔려 있음 | 4번 |
| 패키지 파싱 중 문제 발생 | 파일이 깨짐 (전송 중 끊김) | 다시 받기 |
| 앱이 설치되지 않았습니다 (그 외) | 저장공간 / 잔여 데이터 | 재부팅 후 재시도 |

## 가장 확실한 방법: USB 케이블

위 방법이 다 안 되면 이게 제일 확실합니다.
단, **1번 자동 차단은 먼저 꺼야 합니다** (자동 차단이 USB 설치도 막습니다).

```
1. 설정 ▸ 휴대전화 정보 ▸ 소프트웨어 정보 ▸ 빌드번호 7번 연속 탭
2. 설정 ▸ 개발자 옵션 ▸ USB 디버깅 켜기
3. PC에 USB 연결 → 폰에 뜨는 "USB 디버깅을 허용하시겠습니까?" 허용
```

그다음 PC에서:

```bash
adb install -r IncognitoBlocker-1.0.1.apk
```

`Success` 가 나오면 끝입니다. 자동 차단·Play 프로텍트·출처 설정을 전부 우회합니다.

## 참고: 설치가 되어도 한 단계 더 남았습니다

설치 후 접근성 권한 스위치가 **회색으로 잠겨** 있을 겁니다. 이건 정상이고, 별도 해제가 필요합니다.

```
설정 ▸ 애플리케이션 ▸ IncognitoBlocker ▸ 우측 상단 ⋮ ▸ 제한된 설정 허용
```

그다음에야 `설정 ▸ 접근성 ▸ 설치된 앱 ▸ IncognitoBlocker` 에서 켤 수 있습니다.
