# 갤럭시 S24+ 설정 가이드

S24+에 맞춘 순서입니다. 위에서부터 그대로 따라 하시면 됩니다.

---

## 0. 먼저 알아야 할 S24+ 고유 사실 3가지

### ① 삼성 인터넷은 정책으로 못 막습니다

시크릿 모드를 끄는 키가 **존재하지 않습니다.** 삼성 Knox SDK의 `BrowserPolicy` 클래스를 확인해도
쿠키(`setCookiesSetting`) · 자바스크립트 · 팝업 · 프록시만 있고 시크릿 모드 항목이 없습니다.

따라서 삼성 인터넷은:
- **기본 모드** → 화면 감지로만 차단 (열린 뒤 즉시 닫힘)
- **강력 모드** → 앱 자체를 숨김 처리

두 번째가 확실합니다. 삼성 인터넷을 계속 쓰고 싶다면 화면 감지에 의존해야 하고,
그래서 아래 **6번 진단 모드**로 감지가 실제로 되는지 꼭 확인해야 합니다.

### ② 보안 폴더(Secure Folder)가 가장 큰 구멍입니다

보안 폴더는 별도의 암호화된 사용자 프로필입니다. **접근성 서비스는 보안 폴더 안을 볼 수 없습니다.**
보안 폴더에 삼성 인터넷이나 Chrome을 복제해 넣으면 이 앱은 아무것도 감지하지 못합니다.

→ 진지하게 차단하려면 **보안 폴더를 삭제**해야 합니다.
`설정 ▸ 보안 및 개인정보 보호 ▸ 보안 폴더 ▸ 점 세 개 ▸ 설정 ▸ 제거`

### ③ One UI의 절전 기능이 감시자를 죽입니다

삼성은 백그라운드 앱을 공격적으로 종료합니다. 아래 4번을 건너뛰면 며칠 뒤 조용히 멈춥니다.

---

## 1. APK 설치

`android/app/build/outputs/apk/release/app-release.apk` 를 기기로 보내 설치합니다.

USB로 연결했다면:

```bash
adb install -r app-release.apk
```

## 2. 제한된 설정 허용 (Android 13+ 필수)

스토어 밖에서 설치한 앱은 접근성 권한 스위치가 **회색으로 잠겨** 있습니다.
Google이 악성 앱 방지를 위해 넣은 게이트라 앱이 스스로 풀 수 없습니다.

`설정 ▸ 애플리케이션 ▸ IncognitoBlocker ▸ 오른쪽 위 ⋮ ▸ 제한된 설정 허용`

앱 안의 "앱 정보 열기" 버튼이 이 화면으로 바로 데려다줍니다.

## 3. 접근성 권한 켜기

`설정 ▸ 접근성 ▸ 설치된 앱 ▸ IncognitoBlocker ▸ 켜기`

켜면 상단 알림에 "시크릿 모드: 감시 중" 줄이 생깁니다. 이게 보이면 정상입니다.

## 4. 배터리 최적화 해제 (S24+에서 특히 중요)

두 군데를 모두 손봐야 합니다.

**(a)** `설정 ▸ 배터리 ▸ 백그라운드 사용 제한 ▸ 잠자기 앱 / 딥 슬리핑 앱`
→ 목록에 IncognitoBlocker가 있으면 **제거**

**(b)** `설정 ▸ 애플리케이션 ▸ IncognitoBlocker ▸ 배터리 ▸ 제한 없음`

## 5. 삭제 방지 켜기

앱에서 "삭제 방지 켜기" → 기기 관리자 등록.

> 솔직히: Android 7.0부터 기기 관리자는 자기 해제를 막을 수 없습니다.
> `설정 ▸ 보안 ▸ 기기 관리 앱`에서 해제하면 결국 삭제됩니다.
> **자물쇠가 아니라 과속방지턱입니다.** 진짜 잠금은 8번 강력 모드입니다.

## 6. 진단 모드로 감지 확인 (삼성 인터넷 사용자는 필수)

1. 앱 맨 아래 "진단 모드 켜기"
2. 삼성 인터넷을 열고 **시크릿 모드로 전환**
3. 앱으로 돌아와 "차단 기록"을 봅니다

기록에 `진단 · 삼성 인터넷` 항목과 함께 그 화면에서 실제로 읽힌
`ID:` / `DESC:` / `TEXT:` 값이 남습니다.

- 차단이 제대로 걸렸다면 → 진단 모드를 끄고 끝
- 시크릿 모드가 안 막혔다면 → 기록에 남은 문자열(예: `id/secret_mode_xxx`, `시크릿 모드 사용 중`)을
  `android/app/src/main/java/com/incognitoblocker/core/BrowserRules.kt` 의 `삼성 인터넷` 규칙에 추가하고 다시 빌드

현재 삼성 인터넷 규칙에 들어 있는 신호:

```kotlin
Signal(Kind.VIEW_ID_SUFFIX, "id/secret_mode_layout", 2)
Signal(Kind.VIEW_ID_SUFFIX, "id/tab_bar_secret_badge", 2)
Signal(Kind.TEXT_CONTAINS,  "Secret mode", 2)
Signal(Kind.TEXT_CONTAINS,  "시크릿 모드", 2)
Signal(Kind.CONTENT_DESC,   "Secret mode", 2)
Signal(Kind.CONTENT_DESC,   "시크릿 모드", 2)
```

이 뷰 ID들은 벤더 문서가 아니라 경험적으로 알려진 값이라 One UI 버전에 따라 다를 수 있습니다.
텍스트 신호(`시크릿 모드`)는 대부분 걸리므로 보통은 그대로 작동합니다.

## 7. 보호자 PIN 설정

차단을 끄거나 기록을 지울 때 필요합니다.
**자기 통제용이라면** 본인이 모르는 번호를 다른 사람에게 정하게 하세요.
본인이 아는 PIN은 아무 의미가 없습니다.

## 8. 강력 모드 — 진짜로 막고 싶다면

**대가**: 기기를 공장초기화해야 합니다. device owner는 계정이 하나도 없는 상태에서만 설정할 수 있습니다.

```
1. 중요한 데이터 백업
2. 설정 ▸ 일반 ▸ 초기화 ▸ 공장 초기화
3. 초기 설정에서 Google · 삼성 계정을 추가하지 말고 건너뜁니다
4. 설정 ▸ 휴대전화 정보 ▸ 소프트웨어 정보 ▸ 빌드번호 7번 탭 → 개발자 옵션
5. 개발자 옵션 ▸ USB 디버깅 켜기
6. PC에 USB 연결 후 APK 설치
```

```bash
adb install -r app-release.apk
adb shell dpm set-device-owner com.incognitoblocker/.service.AdminReceiver
adb shell pm grant com.incognitoblocker android.permission.WRITE_SECURE_SETTINGS   # 성인 사이트 차단 잠금(9번)에 필요
```

성공하면 앱 상단이 **"보호 중 · 강력 모드"** 로 바뀝니다.
그 다음 "정책 다시 적용"을 누르면:

| 브라우저 | 처리 |
|---|---|
| Chrome | `IncognitoModeAvailability=1` → 메뉴에서 "새 시크릿 탭" 항목 자체가 사라짐 |
| Edge | `InPrivateModeAvailability=1` → 동일 |
| 삼성 인터넷 | 정책 없음 → **앱 숨김** |
| Firefox / DuckDuckGo / Brave / Opera | 정책 없음 → **앱 숨김** |
| 이 앱 | `setUninstallBlocked` + `setUserControlDisabledPackages` → 삭제·강제종료 불가 |
| 새 브라우저 설치 | `DISALLOW_INSTALL_UNKNOWN_SOURCES` → 차단 |

이후 계정을 추가해도 device owner는 유지됩니다.
**해제는 앱 안의 "보호 완전 해제"(PIN 필요) 뿐입니다.** 설정에서는 해제할 수 없습니다.

> ⚠️ PIN을 잊으면 공장초기화 말고는 방법이 없습니다. 반드시 어딘가에 적어 두세요.

## 9. 성인 사이트 차단 (개인 DNS)

앱 맨 위 **성인 사이트 차단** 카드에서 `켜기` → 필터를 고릅니다. 기본은 CleanBrowsing 가족 필터입니다.

**PC 없이** — 앱이 띄우는 안내대로 직접 넣습니다.

```
설정 ▸ 연결 ▸ 기타 연결 설정 ▸ 개인 DNS
  ▸ 개인 DNS 제공자 호스트 이름
  ▸ family-filter-dns.cleanbrowsing.org  ▸ 저장
```

이 상태에서는 설정에서 바로 끌 수 있고, 끄면 상단 알림이 "성인 사이트: 꺼짐"으로 바뀌기만 합니다.

**PC로 한 번만** — 앱이 개인 DNS를 직접 켜고, 누가 바꾸면 즉시 되돌립니다. 공장초기화가 필요 없습니다.

```bash
adb shell pm grant com.incognitoblocker android.permission.WRITE_SECURE_SETTINGS
```

`install-via-usb.ps1 -GrantSecureSettings` 로 설치하면 같은 권한이 함께 들어갑니다. 끄기·필터 바꾸기·일시 중지는 7번의 PIN이 있어야 합니다.

**강력 모드(8번)** 에서 위 권한까지 주면 개인 DNS 설정 화면 자체가 잠기고("관리자가 차단"), Chrome 설정의 "보안 DNS" 도 꺼집니다. 강력 모드만으로는 잠그지 않습니다 — 앱이 직접 쓸 수 없는 설정을 잠그면 그대로 굳어 버리기 때문입니다.

> 회사·학교 와이파이처럼 포트 853을 막는 곳에서는 인터넷 전체가 끊깁니다. PC로 권한을 줬다면 앱 카드의 **10분 일시 중지**(PIN)를 쓰세요. 10분이 지나면 저절로 다시 켜집니다. 권한 없이 직접 설정했다면 개인 DNS를 '자동'으로 바꾸면 됩니다.
